01 / 工作流

把重复查找，变成一次快捷键。

小面板只在需要时出现。内容按时间排列，搜索覆盖正文和备注，点击即可回填到刚才使用的应用。

文本与图片历史

最近 100 条内容自动归档，显示复制来源和时间。锁定的记录会保留，不随历史清理移除。

正文与备注搜索

为常用地址、模板或代码片段写下用途备注，之后直接搜备注内容定位记录。

贴近光标的浮窗

使用 ⌘ ⇧ V 呼出面板，键盘选择或点击记录即可粘贴到原输入位置。

数据只留在本机

历史内容保存在 macOS 应用数据目录，不会上传到 EasyCopy 服务。自动粘贴需要辅助功能权限。

02 / 数据路径

从剪贴板，到本机历史。

EasyCopy 在后台读取系统剪贴板，将文本和图片保存在 macOS 用户数据目录。没有账户，也没有云端同步。

如需自动回填，请在“系统设置 → 隐私与安全性 → 辅助功能”中授权 EasyCopy。升级后若仍显示未授权，可在应用设置中修复旧版授权，移除旧条目后将 /Applications/EasyCopy.app 重新加入并开启。

03 / 安装

几分钟开始使用。

当前提供 Apple Silicon 版本。安装后从菜单栏打开 EasyCopy，并按需配置快捷键和开机启动。

01

下载并安装

打开 DMG，将 EasyCopy 拖入 Applications。首次打开若出现 macOS 安全提示，使用右键菜单选择“打开”。

02

授予辅助功能

在系统设置的“隐私与安全性 → 辅助功能”中开启 EasyCopy。升级后若仍显示未授权，在应用设置中修复旧版授权，移除旧条目后将 /Applications/EasyCopy.app 重新加入。

03

呼出剪贴板

默认按 ⌘ ⇧ V 打开面板。你可以在设置中录制自己的全局快捷键。
