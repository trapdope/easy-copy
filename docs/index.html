文本和图片历史

自动记录最近 50 条剪贴板内容，支持纯文本和图片，保存在本机。

搜索与快速粘贴

呼出浮窗后可搜索、方向键选择、回车粘贴，也可点击条目直接粘贴。

菜单栏常驻

后台静默运行，不占用 Dock 图标，并支持开机启动和自定义快捷键。

安装方式

1. 下载 DMG

下载后打开 DMG，将 EasyCopy 拖入 Applications。首次打开如果 macOS 拦截，请右键选择“打开”。

2. 开启辅助功能权限

前往“系统设置 > 隐私与安全性 > 辅助功能”，为 EasyCopy 开启权限，以启用自动粘贴。

EasyCopy 数据仅保存在本机。当前下载包为 macOS Apple Silicon 版本。
